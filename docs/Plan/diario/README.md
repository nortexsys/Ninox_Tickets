# Diario

Day-by-day history of the project, one file per close. These are the former `docs/Plan/status/` files, moved
here on 2026-10-20 when the handover became `docs/Plan/ESTADO.md` (a single file, overwritten at every close).
Citations of `docs/Plan/status/<date>.md` elsewhere in the repository mean `docs/Plan/diario/<date>.md`.

Not read at start-up. Read by date, or by the ID (GAP, DEC, T-number) that points here. The files are kept as
they were written: some of their "open points" have since been closed; `ESTADO.md` and the registers are current.
