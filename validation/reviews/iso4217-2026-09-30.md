# ISO 4217 exponent table — review against the published list

Change: `implement-core-model-and-countries`, task 3.1. QA does not edit `lib/`;
this document reports the comparison, not a fix.

## Source

- URL: `https://www.six-group.com/dam/download/financial-information/data-center/iso-currrency/lists/list-one.xml`
  (the maintenance agency's own spelling, `iso-currrency`, reproduced exactly).
- Fetched: 2026-09-30, with `curl -sSL`, saved under the system temp directory
  (not in the worktree).
- List's `Pblshd` attribute: **2026-09-17** — the same date the doc-comment in
  `packages/paperdrop_core/lib/src/money/currency.dart` already cites as the
  transcription source.

## Method

- Parsed every `CcyNtry` element of the published list (277 entries, one per
  country/territory that uses a currency).
- Built the published map alphabetic code → `CcyMnrUnts`, skipping the 13
  entries whose `CcyMnrUnts` is `N.A.` (no minor unit, e.g. `XXX`, gold/silver
  codes) and de-duplicating codes shared by several countries (e.g. `EUR` is
  listed once per euro-area country; all instances agree on `CcyMnrUnts` — no
  conflicting duplicate was found).
- Result: **165 unique alphabetic codes with a numeric minor-unit exponent** in
  the published list.
- Compared against every `CurrencyCode._('XXX', n)` entry in
  `packages/paperdrop_core/lib/src/money/currency.dart` (**165 entries**), in
  both directions.

## Result

**165 codes compared, zero differences in either direction.**

- Mismatched exponent (same code, different value): **none**.
- Codes in `lib/` absent from the published list: **none**.
- Codes in the published list absent from `lib/`: **none**.

No table of differences follows because there are none to show.
